# Evidence collection (templates only)

This directory deliberately contains no fabricated screenshots, logs, results, or claims of execution. Use it only after running demonstrations in your own authorised environment.

Before capturing evidence, remove credentials, personal data, private IP/host details when required, API tokens, and packet payloads. Record tool version, date, command, and whether the environment was an authorised lab.

Suggested files are described in `EVIDENCE_TEMPLATE.md`. Store only redacted, learner-approved materials and follow your organisation's retention policy.
