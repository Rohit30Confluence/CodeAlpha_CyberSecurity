What would impress a reviewer

Show the detection

Don't spend the whole video reading code. Run the IDS demo, show the alert, then point to the rule that caused it.

Show the reasoning

For phishing, explain one scenario and why the red flags matter. For secure coding, show one finding and the recommended fix.

Own the limitations

Saying “this is a focused educational reviewer” is more credible than calling it a production SAST platform.

Keep evidence clean

Use only real output. Redact credentials, personal data and private infrastructure details where necessary.
