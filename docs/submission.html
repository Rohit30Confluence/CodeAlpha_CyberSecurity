Submission checklist

Finish the presentation layer and evidence. Avoid last-minute feature churn.

Repository

  • Repository name follows the required CodeAlpha project naming convention.
  • README opens with a clear explanation of all four tasks.
  • Tests and reproducible commands are present.
  • No secrets, tokens or fabricated evidence are committed.

Three strongest demonstrations

  1. Sniffer: run the metadata demonstration and explain the fields.
  2. Phishing: complete several scenarios and show the scoring/explanations.
  3. Suricata: validate the configuration and, where available, replay the deterministic lab PCAP and show the alert.

LinkedIn / video

  • Record a short walkthrough rather than a long screen dump.
  • Start with the problem and what was built.
  • Show one concrete result from each selected task.
  • Link the GitHub repository.
  • Tag CodeAlpha as requested by the internship instructions.
Important: Do not state that a command was executed if it was only documented. Do not manufacture screenshots. Real evidence is more valuable than polished but unverifiable evidence.
