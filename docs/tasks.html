Task review

What each task actually demonstrates

This page is intentionally concrete: requirement → implementation → proof → limitation.

01 · Basic Network Sniffer

Implementation

Packet summaries expose timestamp, source, destination, protocol, length and ports. Scapy is optional for bounded live capture.

Review

Strong. It demonstrates packet structure and traffic metadata while avoiding payload disclosure. The intentional payload omission should be explained during the presentation.

02 · Phishing Awareness Training

Implementation

Ten interactive scenarios with explanations, category feedback and an overall score. Topics include lookalike domains, QR links, MFA fatigue, impersonation, malicious updates and safe reporting.

Review

Strong. The content maps well to the awareness requirement. A short screen recording of the quiz makes this much easier for a reviewer to understand.

03 · Secure Coding Review

Implementation

Python AST inspection identifies eval, exec, pickle.loads and subprocess shell execution, returning severity and remediation.

Review

Needs the most presentation care. It is a useful focused reviewer, but it should be presented honestly as a narrow educational static-analysis exercise rather than a complete application security audit.

04 · Network IDS

Implementation

Suricata 7.0.8 container configuration, three local detection rules, fast.log/eve.json output and deterministic offline PCAP replay. The Python IDS remains a companion demonstration.

Review

Strongest task. This directly addresses CodeAlpha's Suricata requirement and provides a defensible lab demonstration without touching an external network.

Engineering checks

The repository reports an 11-check pytest suite covering packet summarisation, phishing scenarios, secure-review findings, IDS behavior and Suricata assets. Live capture and PCAP replay remain separate environment-dependent demonstrations.

Keep the presentation factual. Never add screenshots or results that were not actually produced.
