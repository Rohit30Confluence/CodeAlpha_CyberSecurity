# CodeAlpha Presentation Pack

Static presentation pages for the CodeAlpha Cyber Security internship repository.

Pages:
- `index.html` — portfolio landing page
- `tasks.html` — task-by-task implementation review
- `review.html` — evaluator-style technical assessment
- `submission.html` — submission checklist
- `feedback.html` — improvement/engineering feedback

## GitHub Pages

Copy these files into a `docs/` folder in the repository, or publish them from a dedicated branch. GitHub Pages can publish a static `index.html` from a repository source folder.

Before publishing, replace any evidence placeholders with only genuine screenshots/results from actual authorised runs.
