Internship portfolio · September 2026

Four security exercises, built as one practical portfolio.

A working repository covering packet analysis, phishing awareness, secure coding review and network intrusion detection. The emphasis is on reproducible demonstrations, defensive use and clear limits rather than pretending this is a production security platform.

Public repository Python Scapy Suricata

What I built

01

Network Sniffer

Packet metadata summarisation with bounded, opt-in capture. Source, destination, protocol, ports and lengths are visible without dumping payload contents.

02

Phishing Awareness

A 10-scenario interactive training flow covering lookalike domains, QR links, MFA fatigue, impersonation, malicious updates and reporting.

03

Secure Coding Review

A Python AST-based reviewer for selected high-risk constructs, with severity and remediation guidance. Deliberately scoped as an educational static check.

04

Network IDS

A Suricata lab with local rules, structured alerts and deterministic offline PCAP replay, alongside a small Python IDS engine.

Proof over promises

Reproducible

Commands and expected outcomes are documented in the repository. The automated suite covers the core exercises.

Controlled

Network demonstrations are designed for an authorised lab or self-owned environment. The Suricata demonstration uses offline traffic replay.
